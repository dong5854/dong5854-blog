# dong5854's blog

Next.js 16 (App Router) 기반 개인 기술 블로그

## 기술 스택

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Content**: MDX + Velite
- **Styling**: Tailwind CSS
- **Search**: kbar
- **Deploy**: Vercel
- **Analytics**: Cloudflare Web Analytics

## 시작하기

```bash
yarn install
yarn dev
```

## 스크립트

| 명령어       | 설명                          |
| ------------ | ----------------------------- |
| `yarn dev`   | 개발 서버 (Velite watch 포함) |
| `yarn build` | 프로덕션 빌드                 |
| `yarn serve` | 프로덕션 서버                 |
| `yarn lint`  | ESLint 실행                   |

### 로컬 MDX 편집기

`yarn dev` 실행 후 `http://localhost:3000/dev/editor` 또는 헤더의 **글 편집**을 엽니다.
**새 글**에서 제목·파일 이름·작성일을 입력하고 저장 폴더를 선택하면 새 폴더와 MDX 초안을 만들 수 있습니다.
**+ 새 폴더**로 새 디렉터리를 직접 지정할 수도 있습니다. 최종 저장 경로를 폼에서 확인하세요.
**초안 (배포 시 숨김)**을 해제하고 저장하면 배포 대상에 포함됩니다.
검색형 글 선택 메뉴에서 기존 `data/blog/**/*.mdx` 글을 선택하면 제목·태그·본문을 수정하고 실시간 미리보기를 볼 수 있습니다.
본문 미리보기는 브라우저의 Web Worker에서 처리하며 입력마다 서버 요청이나 파일 쓰기를 하지 않습니다.
처음 글을 열 때 변환기를 한 번 불러오고, 이후 즉시 변환합니다. 코드 색상은 입력이 300ms 멈춘 뒤 적용합니다.
**파일 저장** 또는 `⌘S` / `Ctrl+S`로 원본 파일에 반영합니다. 다른 메타데이터는 보존되며,
외부 편집기에서 변경된 파일은 덮어쓰지 않습니다. 충돌 시 내용을 복사한 뒤 **다시 불러오기**를 사용하세요. 미저장 변경이 있으면 페이지를 나갈 때 확인합니다.

수정 내용은 입력이 400ms 멈추면 브라우저에 임시저장됩니다. 다시 접속하면 임시저장 글 목록에서 열어 **임시저장 복구**를 선택하세요.
원본 파일 저장과 별개이며, 브라우저 데이터 삭제 시 사라집니다. 같은 브라우저와 주소(호스트·포트)에서 복구할 수 있습니다.
좌우 분할 화면의 **스크롤 연동**은 Markdown 문단·제목·목록·이미지·코드 블록과 기본 MDX 이미지·출처·참고 상자의 원문 위치를 기준으로 맞추며 끌 수 있습니다. 이미지 로딩과 화면 크기 변경 시 위치를 다시 계산합니다. 임의의 MDX 컴포넌트는 주변 문단 사이에서 위치를 보간합니다.
**검색·바꾸기** 또는 `⌘F` / `Ctrl+F`로 본문을 검색합니다. 대소문자를 구분하며 정규식 대신 입력한 문자열 그대로 찾습니다.
이전·다음 결과 이동, 한 곳·전체 바꾸기와 실행 취소를 지원합니다.
본문에서 `⌘/Ctrl+B`는 굵게, `⌘/Ctrl+I`는 기울임, `⌘/Ctrl+K`는 링크를 삽입합니다. 서식 버튼도 실행 취소할 수 있습니다.
목록·체크리스트·인용에서 Enter로 다음 항목을 이어 쓰고, 빈 항목에서 Enter로 종료합니다. 코드 블록 안에서는 목록 자동 완성을 하지 않습니다.
Tab / Shift+Tab은 들여쓰기·내어쓰기, Esc는 편집창에서 포커스를 해제합니다.
**이미지 편집**에서 붙여넣은 이미지나 기본 Markdown 이미지의 설명·너비(1~2400px, 빈칸은 원본)·정렬을 조절합니다.
`![이미지 설명](주소)`의 설명은 이미지 바로 아래에 작은 회색 캡션으로 표시됩니다. 설명을 비우면 캡션을 표시하지 않습니다. 미리보기와 실제 글에 동일하게 적용됩니다.
설정을 적용하면 블로그와 미리보기에서 함께 지원하는 `ContentImage` MDX로 저장됩니다. 임의의 JSX 이미지나 참조형 이미지 문법은 메뉴 편집 대상에 포함되지 않습니다.
**변경 비교**에서 마지막으로 불러오거나 저장한 버전과 현재 제목·태그·초안 여부·본문을 비교할 수 있습니다. 비교 창을 여는 것만으로 파일이 저장되지는 않습니다.

**출처** 버튼은 커서 위치에 `<Source label="출처" title="제목" href="링크" />`를 바로 삽입합니다. 제목과 링크를 실제 문서 이름과 HTTP(S) 주소로 바꾸세요.
앞 문구는 `label="참고 문서"`처럼 바꿀 수 있습니다. 생략하면 `출처`이며, `label=""`이면 앞 문구와 여백을 숨깁니다.
링크 없이 이름만 표시하려면 `<Source title="Gemini" />`처럼 `href`를 생략합니다.
이미지 바로 다음에 넣은 출처는 이미지와의 간격을 좁혀 표시합니다.
**참고 상자** 버튼은 `<Note title="참고" text="내용" />`를 삽입합니다. 제목과 내용을 본문에서 직접 수정하세요.
별도 입력 패널은 열리지 않으며, 선택한 본문이 있으면 해당 부분을 대체합니다. 삽입은 실행 취소할 수 있고 블로그와 미리보기에 동일하게 표시됩니다.
일반 인용문의 자동 따옴표도 제거했습니다. 직접 입력한 따옴표는 유지됩니다.

본문에 이미지를 붙여넣거나 드래그하고, **이미지** 버튼으로 파일을 선택할 수도 있습니다.
이미지 삽입은 `⌘Z` / `Ctrl+Z`로 되돌리고, 브라우저의 다시 실행 단축키로 복원할 수 있습니다.
PNG/JPEG/GIF/WebP(최대 10MB)를 `public/static/images/editor/`에 저장하고 이미지 문법을 삽입합니다.
이미지는 업로드 즉시 저장되므로 글에서 제거하거나 저장을 취소해도 이미지 파일은 남습니다.
글과 함께 해당 이미지 파일을 Git에 포함하세요.

편집 페이지와 API는 `NODE_ENV=development` 및 localhost 요청에서만 동작합니다.
프로덕션에서는 404를 반환하며 별도 백엔드 서비스는 필요하지 않습니다.
회귀 검사는 `node scripts/test-dev-editor.mjs`, `node scripts/test-preview-queue.mjs`, `node scripts/test-local-preview.mjs`, `node scripts/test-editor-tools.mjs`, `node scripts/test-editor-extras.mjs`로 실행합니다.
저장 단축키와 양식 검사는 `node scripts/test-editor-save-shortcut.mjs`, `node scripts/test-editor-templates.mjs`로 실행합니다.

스크롤 위치 연결 검사는 `node scripts/test-editor-scroll-sync.mjs`로 실행합니다.
