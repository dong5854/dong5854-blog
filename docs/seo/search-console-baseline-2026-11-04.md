# Search Console 확인과 내부 링크 개선

확인일: 2026년 11월 4일

대상 속성은 `https://blog.movingzero.org/`이며 검색 유형은 웹이다. 아래 수치는 Search Console 화면에서 확인한 값이다. 수동 Google 검색에서 관찰한 순위와 구분한다.

## 검색 성과 기준값

| 보고서      | 클릭수 | 노출수 | 검색어 표   | 페이지 표    |
| ----------- | ------ | ------ | ----------- | ------------ |
| 최근 28일   | 0      | 0      | 데이터 없음 | 데이터 없음  |
| 최근 24시간 | 0      | 2      | 데이터 없음 | 5개 URL 표시 |

28일 보고서를 선택했지만 차트에 표시된 데이터 날짜는 2026년 11월 1일뿐이었다. 마지막 업데이트 표시는 4시간 전이었다. 최근 배포의 성과를 판단할 자료가 충분하지 않다.

24시간 보고서의 차트 날짜는 2026년 11월 2일부터 11월 3일까지로 표시됐다. 이 보고서는 잠정 데이터다. YARN 스케줄러 비교 글은 페이지 표에서 노출 1회와 클릭 0회로 확인됐다. 홈페이지와 태그 목록 및 다른 글 2개도 각각 노출 1회로 표시됐다. 사이트 전체 합계와 페이지별 합계는 집계 방식이 달라 일치하지 않을 수 있다.

24시간 보고서의 평균 게재순위 표시는 1이었다. 검색어 표가 비어 있으므로 이를 `yarn 스케줄러`나 `spark 스케줄러`의 순위로 해석할 수 없다. 본인 테스트에서 발생한 노출인지도 확인할 수 없다.

## 사이트맵

- 공개 `/sitemap.xml`은 HTTP 200으로 응답했다.
- 운영 도메인의 중복 없는 URL 29개를 포함했다.
- YARN 스케줄러 비교 글이 포함되어 있었다.
- Search Console의 제출 상태는 성공이었다.
- 제출일과 마지막으로 읽은 날짜는 모두 2026년 11월 2일이었다.
- 발견된 페이지는 29개였다. 발견됐다는 사실만으로 모든 페이지의 색인이 완료됐다고 판단하지 않는다.

## 이번 변경

글 제목과 본문은 그대로 유지했다. 공통 글 레이아웃에 ‘함께 읽을 글’을 추가했다.

공통 태그가 많은 공개 글을 먼저 표시하고 같은 점수에서는 최근 글을 먼저 표시한다. 자신과 초안은 제외한다. 관련 태그가 없으면 표시하지 않으며 최대 3개를 연결한다. 링크는 초기 HTML에 실제 주소가 있는 앵커로 출력한다.

## 이후 비교 방법

Search Console의 확정 데이터에 변경 이후 날짜가 포함되면 같은 웹 검색 조건에서 변경 전후 기간을 비교한다. 전체 수치와 글별 수치를 함께 확인한다. 검색어 데이터가 생기면 YARN과 Spark 관련 검색어의 노출수 및 평균 게재순위를 따로 기록한다. 검색어 표에 없다는 사실만으로 해당 검색어의 노출이 반드시 0이라고 단정하지 않는다.

관련 글 연결은 페이지 발견과 탐색을 돕는 작업이다. 이번 배포만으로 일반 검색어의 순위가 개선됐다고 판단하지 않는다.
