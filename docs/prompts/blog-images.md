# 블로그 이미지 생성 프롬프트

썸네일과 본문 설명 이미지를 만들 때 아래 프롬프트를 복사하고 대괄호 부분을 바꿔 사용합니다.
썸네일은 글자 없이, 본문 설명 이미지는 필요한 짧은 라벨만 넣는 것을 기본으로 합니다.

```text
한국어 개발자 블로그에 사용할 기술 이미지를 만들어줘.

주제: [예: YARN의 Capacity Scheduler와 Fair Scheduler]
용도: [썸네일 / 본문 개념 설명 / 구조도 / 비교 그림]
전달할 핵심: [이미지를 보고 독자가 이해해야 할 내용을 한 문장으로]
필수 요소: [반드시 들어가야 할 대상이나 관계]
비율: [썸네일은 16:9, 본문은 내용에 맞게]

디자인:
- 짙은 남색 배경(#0B101B), 밝은 회색과 흰색, 에메랄드 포인트(#10B981)를 사용한다.
- 차분하고 정돈된 기술 문서 스타일로 만든다.
- 단순한 도형, 일정한 선 두께, 넉넉한 여백으로 구성한다.
- 핵심 대상이 먼저 보이도록 크기와 대비에 명확한 차이를 둔다.
- 색은 의미를 구분하는 데 사용하고, 같은 의미에는 같은 색을 쓴다.
- 작은 화면에서도 주요 구조를 알아볼 수 있도록 요소 수를 제한한다.

표현:
- 썸네일은 핵심 개념 하나를 시각적으로 압축한다.
- 본문 설명과 구조도는 실제 동작·연결·방향이 정확하게 드러나게 한다.
- 비교 그림은 양쪽의 크기와 기준을 맞춰 차이가 쉽게 보이게 한다.
- 주제와 관계없는 장식, 의미 없는 연결선, 과도한 입체 효과는 제외한다.
- 로봇, 뇌, 빛나는 회로처럼 상투적인 AI 이미지는 주제에 꼭 필요할 때만 사용한다.

텍스트:
- 제목과 긴 설명은 이미지에 넣지 않는다.
- 이해에 꼭 필요한 짧은 라벨만 사용한다.
- 기술 용어는 원래 표기를 유지하고, 알아볼 수 없는 글자나 가짜 코드는 넣지 않는다.
- 로고, 워터마크, 서명은 넣지 않는다.

시각적 화려함보다 개념의 정확성과 가독성을 우선해 완성해줘.
```
